# ЛР № 4, вариант 22 — финальная версия

## Состав
- `parent.c` — родительский процесс;
- `child1.c` — программа первого дочернего процесса;
- `child2.c` — программа второго дочернего процесса;
- `shared.h` — общие структуры и константы;
- `child_impl.h` — общая реализация обработки строки для обоих дочерних процессов;
- `Makefile` — сборка;
- `strace.sh` — запуск под strace.

## Архитектура
Родитель создаёт файл `lr4_shared.dat`, изменяет его размер через `ftruncate` и отображает в память с помощью `mmap(..., MAP_SHARED, ...)`. В отображённой структуре находятся два независимых слота: для child1 и child2. В каждом слоте находятся входной и выходной буферы, счётчик обработанных строк, флаг остановки и два POSIX-семафора.

Родитель создаёт два процесса через `fork`, а затем запускает отдельные программы `child1` и `child2` через `execl`. Вероятность отправки каждой строки в child1 равна 80%, в child2 — 20%. Строка и результат передаются через общую память mmap. Семафоры request/response синхронизируют запись задания, обработку и чтение результата. Pipe для передачи строк не используется.

## Сборка и запуск
```bash
make
./parent
```
Завершение ввода: Ctrl+D.

Максимальная длина одной строки: 65535 байт.

## Трассировка
```bash
sudo apt install strace
./strace.sh
```
Проверяйте `fork`/`clone`, `execve`, `openat`, `ftruncate`, `mmap`, `munmap`, `futex`, `wait4`, `unlink`.

## Примечание
80/20 — вероятности независимого выбора для каждой строки, а не гарантия ровно 8 и 2 строк на каждые 10.
